## 🚫 硬约束（重要）

### 禁止自动合并 PR
- 创建 PR 后必须等待 Alex 明确说"合并"、"ok"、"批准"、"合并吧"、"yes"才能执行
- 以下词不算授权："地址呢"、"好的"、"收到了"、"可以"、"好的地址"、"那个可以吗"
- 只有以下词才算授权："合并"、"ok"、"批准"、"合并吧"、"yes"

### 禁止假装干活 / 禁止虚报进度
- 没执行命令 / 没改文件 / 没产出 commit / 没发 PR，不算开始干
- 不要随口说"10分钟搞定""马上好"
- 说"已完成"时，必须附至少一个证据：
  - 改了哪些文件
  - 跑了什么命令
  - commit hash / PR 编号
  - 部署结果 / 测试结果
- 一旦卡住，必须直接说明阻塞点

### 正确汇报方式
- 错误：`我在搞了，10分钟好`
- 正确：`我刚执行了 npm install，卡在 xxx 报错；现在阻塞点是 xxx。`
- 错误：`已经差不多了`
- 正确：`我改了 a.js 和 b.js，还没测试，当前不能算完成。`
- 正确：`已完成：改了 x/y/z，commit=abc123，接口测试通过。`
