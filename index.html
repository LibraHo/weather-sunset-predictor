火烧云计算方法

火烧云指数综合评估天空条件与光学传播路径，判断当日形成火烧云的概率与强度。以下为基于气象数据的完整计算原理。

1. 云种判别与画布评分

画布评分权重： 中高云 70%，中云 45%，低云 10%

云种识别规则：

  • 层云型：低云 >70% → 画布乘数 0.4，低云遮挡明显
  • 层积云型：40% ≤ 低云 ≤70% → 画布乘数 0.6，部分遮挡
  • 晴空型：总云量 <30% → 画布乘数 0.85，光线通透
  • 积云型：中云为主或云底 <500m → 画布乘数 0.5，中性效果

画布评分 = (云量评分 × 云种乘数)

2. 光路几何模型

评估光线路径上空域的云况，计算光线透过概率。

双点采样法：

  • 近点（Near）：距观测点 150km，权重 40%
  • 远点（Far）：距观测点 300km，权重 60%

光路评分规则：

  • 近点或远点云量 <20% → 光路评分 100 分
  • 近点云量 20-40% 且远点 <20% → 80 分
  • 远点云量 20-40% → 60 分
  • 任一点云量 >40% → 40 分以下

光路评分 = 近点×40% + 远点×60%

3. 气溶胶光学厚度（AOD）修正

AOD 衡量大气气溶胶浓度，高值会显著降低光线透过率。

AOD 阈值分级：

  • AOD < 0.3 → 修正系数 1.0（空气质量优良）
  • 0.3 ≤ AOD < 0.5 → 修正系数 0.85
  • 0.5 ≤ AOD < 0.7 → 修正系数 0.7
  • AOD ≥ 0.7 → 修正系数 0.5（雾霾严重）

AOD修正系数直接降低最终评分

4. 渲染系数

综合大气透明度、湿度与降水状况，修正视觉效果。

能见度修正：

  • 能见度 ≥ 30km → 修正系数 1.0
  • 20 ≤ 能见度 <30km → 修正系数 0.95
  • 10 ≤ 能见度 <20km → 修正系数 0.85
  • 能见度 <10km → 修正系数 0.7

湿度修正：

  • 40% ≤ 湿度 ≤ 70% → 修正系数 1.0（最佳渲染）
  • 湿度 <40% 或 >80% → 修正系数 0.85

降水修正：

  • 无降水或微量降水（<1mm/h）→ 修正系数 1.0
  • 1 ≤ 降水 <5mm/h → 修正系数 0.7
  • 降水 ≥5mm/h → 修正系数 0.4（雨中不宜）

渲染系数 = 能见度修正 × 湿度修正 × 降水修正

5. 置信度评级规则

综合评估预测可靠性的多维度判别规则：

  • 云量边界梯度：水平方向云量差异大 → 边界清晰度高
  • 风速风向一致性：风速 >15m/s 且风向不一致 → 降低置信度
  • 太阳高度角窗口：太阳在地平线以下 >6° 或以上 >5° 外 → 降低置信度

评分解读

优秀 >70 分 强烈推荐出门，火烧云概率极高
良好 40-70 分 可观赏，条件较好
一般 20-40 分 谨慎期待，可能形成但概率不高
不佳 <20 分 不建议，条件欠佳
