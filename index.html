火烧云计算方法

火烧云指数综合评估天空条件与光学传播路径，判断当日形成火烧云的概率与强度。以下为基于气象数据的完整计算原理。

1. 云种判别与画布评分 Cloud ID & Canvas Score

画布评分权重 Weights: 中高云 70%，中云 45%，低云 10%
(Mid/High Cloud 70%, Mid Cloud 45%, Low Cloud 10%)

云种识别规则 Cloud Rules:

  • 层云型 Stratus: 低云 >70% → 画布乘数 0.4
    (Low Cloud >70% → Canvas Multiplier 0.4)
  • 层积云型 Stratocumulus: 40% ≤ 低云 ≤70% → 乘数 0.6
    (40% ≤ Low Cloud ≤70% → Multiplier 0.6)
  • 晴空型 Clear Sky: 总云量 <30% → 乘数 0.85
    (Total Cloud <30% → Multiplier 0.85)
  • 积云型 Cumulus: 中云为主/云底<500m → 乘数 0.5
    (Mid Cloud Dominant/Base<500m → Multiplier 0.5)

画布评分 = 云量评分 × 云种乘数
(Canvas Score = Cover Score × Species Multiplier)

2. 光路几何模型 Optical Path Geometric Model

评估光线路径上空域的云况。
Evaluates cloud conditions along the light path.

双点采样法 Two-point Sampling:

  • 近点 Near Point: 距观测点 150km, 权重 40%
    (Distance 150km, Weight 40%)
  • 远点 Far Point: 距观测点 300km, 权重 60%
    (Distance 300km, Weight 60%)

评分规则 Scoring Rules:

  • 近/远点云量 <20% → 100 分 (Near/Far <20% → 100)
  • 近点 20-40% 且远点 <20% → 80 分 (Near 20-40%, Far <20% → 80)
  • 远点云量 20-40% → 60 分 (Far 20-40% → 60)
  • 任一点云量 >40% → 40分以下 (Any >40% → <40)

光路评分 = 近点×40% + 远点×60%
(Path Score = Near×40% + Far×60%)

3. 气溶胶(AOD)修正 Aerosol Optical Depth Correction

AOD 衡量大气气溶胶浓度，高值降低透光率。
High AOD reduces light transmission.

AOD 阈值 AOD Thresholds:

  • AOD < 0.3 → 系数 1.0 (空气优 Air Quality Excellent)
  • 0.3 ≤ AOD < 0.5 → 系数 0.85 (Good)
  • 0.5 ≤ AOD < 0.7 → 系数 0.7 (Fair)
  • AOD ≥ 0.7 → 系数 0.5 (雾霾严重 Heavy Haze)

最终评分 = 基础分 × AOD系数
(Final Score = Base Score × AOD Coefficient)

4. 渲染系数 Rendering Coefficient

综合大气透明度、湿度与降水。
Corrects based on transparency, humidity, and precip.

能见度 Visibility:

  • ≥30km → 1.0 | 20-30km → 0.95 | 10-20km → 0.85 | <10km → 0.7

湿度 Humidity:

  • 40% - 70% → 1.0 (最佳 Best) | <40% 或 >80% → 0.85

降水 Precipitation:

  • <1mm/h → 1.0 | 1-5mm/h → 0.7 | ≥5mm/h → 0.4 (雨中不宜 Rain)

系数 = 能见度 × 湿度 × 降水
(Coef = Vis × Hum × Precip)

5. 置信度评级规则 Confidence Level Rules

多维度判别预测可靠性。
Criteria for evaluating prediction reliability.

  • 云量边界 Cloud Edge: 梯度大 → 边界清晰
    (Large gradient → High clarity)
  • 风速风向 Wind Consistency: 风速 >15m/s 且风向不一致 → 降低置信度
    (Wind >15m/s & inconsistent → Lower confidence)
  • 太阳高度角 Solar Altitude: 在地平线以下 >6° 或以上 >5° 外 → 降低置信度
    (Sun >6° below or >5° above horiz. → Lower confidence)

评分解读 Score Guide

优秀 Excellent >70 分 (>70) 强烈推荐出门 Highly Recommended
良好 Good 40-70 分 (40-70) 可观赏，条件较好 Viewable, Good Conditions
一般 Fair 20-40 分 (20-40) 谨慎期待 Cautious, Low Probability
不佳 Poor <20 分 (<20) 不建议 Not Recommended
