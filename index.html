火烧云计算方法

火烧云指数综合评估天空条件与光学传播路径，判断当日形成火烧云的概率与强度。以下为基于气象数据的完整计算原理。

算法版本：2026.05.11-opening-upper-cloud-carrier-v1 本版优化光路判断：低云会遮住太阳光，中高云更多作为晚霞画布，不再只因为总云量高就压低光路。

版本更新记录

用于回溯每次算法调整的原因、影响和验证方式
  1. 2026-05-10
    低云主导光路 v3

    光路主要看低云和太阳方向是否挡光；高云、中云丰富时优先当作晚霞画布处理。

    验证：高云满天但低云很少的样本不再被当作阴天；低云主导、降水样本仍保持低分。

1. 云层结构 Cloud Structure · 画布评分

火烧云需要合适的云层作为"画布"，高云和中云是核心载体，低云起遮挡作用。

  • 高云（>6km）：火烧云的最佳载体，透光性好，能染出大片红橙色
  • 中云（2–6km）：同样能产生火烧云，效果略逊于高云
  • 低云（<2km）：主要起遮挡作用，不贡献正面分数

高云分 = 25 × exp(−(高云−50)²/800)，最优50%，满分25
中云分 = 高云≥40%时更宽容（中云也是色彩载体），否则严格高斯
低云加分 = 10 × max(0, 1−低云/20)，越低越好，满分10

2. 光路评估 Light Path · 光路评分

光路通畅度决定阳光能否照到可染色的中高云。低云挡在太阳方向时会明显拉低光路；中高云多时通常先看作晚霞画布。

  • 低云少时光路更容易打开；低云主导或太阳方向有低云墙时，光线更难照到云层
  • 能见度：影响光线传播清晰度

光路分 = 太阳角度与云底高度估算 + 低云遮挡 + 太阳方向走廊修正

3. 大气透明度 Transparency · 25分

透明的大气让光线更纯粹地染色云层，湿度适中有助于散射增强色彩。

  • 能见度：15 × (1 − e^(−v/15))，满分15分
  • 湿度：最优55%，高斯曲线，满分10分

透明度分 = 能见度分 + 湿度分（最高25分）

4. 云层立体感 Layer Diversity · 15分

高中低三层云同时存在时，光线折射角度多样，色彩层次更丰富。

  • 三层云均>10% → 15分
  • 任意两层>10% → 8分
  • 仅一层或无云 → 0分

5. 低云惩罚系数 Low Cloud Penalty · Multiplier

低云挡在视线前方，是火烧云的"视线杀手"，以乘性系数惩罚总分。

  • 低云<20% → ×1.0（无惩罚）
  • 低云20–40% → ×1.0 到 ×0.8（线性）
  • 低云40–70% → ×0.8 到 ×0.5（线性）
  • 低云>70% → ×0.2（严重遮挡）

6. 降水惩罚系数 Precipitation Penalty · Multiplier

降水直接削弱火烧云可见性，以乘性系数惩罚总分。

  • 降水<0.1mm/h → ×1.0（无惩罚）
  • 0.1–0.5mm/h → ×0.85
  • 0.5–2mm/h → ×0.5
  • >2mm/h → ×0.15（大雨，基本无望）

最终得分 = 基础分 × 低云系数 × 降水系数

7. 厚高云与灰幕修正 Cloud Thickness · Canvas Quality

高云多不一定代表高分；算法会区分“可被染色的中高云载体”和“遮光灰幕”。前者按云面质量修正，后者结合空气质量判断。

  • 中高云载体明确：高云很充足，或中高云同时存在且太阳方向有透光开口，低云少、无降水且空气不灰
  • 这类场景按可染色云面质量修正画布分，光路判断保持独立
  • 如果云幕很厚或空气发灰，颜色会变暗、变淡

最终修正 = 云面质量修正 + 灰幕/沙尘/降水/几何限制等独立条件

API接入

霞客 Agent API 提供地点解析、朝霞/晚霞评分和评分解释，适合个人、学习与研究场景。

OpenAPI 规格 管理后台

快速开始

  1. 申请并获取 Token。
  2. 请求时在 Authorization: Bearer <token> 中传入。
  3. 调用 /api/agent/forecast、/api/agent/explain 或 /api/agent/geocode。

使用限制

仅限个人/学习/研究用途，禁止商用。公开展示请脱敏并标明来源。

示例调用

curl -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  "https://sunset.bjhyc.online/api/agent/explain?location=%E5%8C%97%E4%BA%AC&type=sunset&date=today"

核心接口

/forecast返回评分、质量等级和最佳观赏窗口。
/explain返回评分构成、关键限制和自然语言解释。
/geocode返回地点候选、坐标和置信度。

数据来源：Open-Meteo（GFS + ECMWF）
