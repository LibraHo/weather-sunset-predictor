# 霞客微信小程序平台配置与验收清单

本清单用于霞客原生微信小程序上线前配置、调试、真机验收和发布证据记录。线上域名口径统一使用 `https://sunset.bjhyc.online`。

## 1. 微信后台基础配置

- [ ] 确认小程序 AppID，替换开发阶段 `touristappid`。
- [ ] 确认小程序名称、头像、简介与“霞客”品牌一致。
- [ ] 确认服务类目覆盖天气查询、地图位置、图片上传/分享相关能力；若类目不支持定位或照片能力，先调整类目再提审。
- [ ] 配置体验成员，至少包含 Alex、开发测试账号、iOS 真机账号、Android 真机账号。
- [ ] 配置线上版本备注，说明本次包含：首页查分、地点搜索、结果页、分享地图入口、照片上传。
- [ ] 保存 AppID、基础库版本、开发者工具版本、上传者、上传时间。

## 2. 合法域名配置

所有域名必须使用 HTTPS，且证书链正常。

- [ ] request 合法域名：`https://sunset.bjhyc.online`
- [ ] uploadFile 合法域名：`https://sunset.bjhyc.online`
- [ ] downloadFile 合法域名：`https://sunset.bjhyc.online`
- [ ] web-view 业务域名：`https://sunset.bjhyc.online`
- [ ] 提审前关闭微信开发者工具里的“不校验合法域名、web-view 域名、TLS 版本以及 HTTPS 证书”。
- [ ] 真机验证接口请求不依赖本地代理、不依赖调试开关。

## 3. 权限与隐私协议

- [ ] 位置权限用途：用于查询当前位置的火烧云预测、附近地点和分享地图定位。
- [ ] 相册/拍摄权限用途：用于用户选择或拍摄晚霞照片并投稿到分享地图。
- [ ] 网络请求用途：用于调用霞客后端预测、地理编码、照片上传和用户收藏接口。
- [ ] 隐私协议包含收集项：位置坐标、地点名称、上传照片、拍摄时间、上传者昵称或用户标识。
- [ ] 隐私协议说明照片会用于公开分享地图展示，上传前必须让用户明确知道。
- [ ] 授权拒绝时页面可继续使用手动搜索地点，不应卡死在定位流程。
- [ ] 用户未授权相册/拍摄时，照片上传页给出可恢复路径。

## 4. 小程序项目配置

- [ ] `miniprogram/project.config.json` 使用真实 AppID。
- [ ] 基础库版本不低于当前测试确认版本，默认记录为 `3.3.5` 或更高。
- [ ] `miniprogram/app.json` 页面路径包含：首页、结果页、分享地图页、照片上传页。
- [ ] 导航栏标题和视觉主题符合霞客当前深色设计语言。
- [ ] sitemap 配置符合搜索开放要求，敏感后台页面不得暴露。
- [ ] 构建包大小满足微信小程序限制；图片资源避免直接打进包内。

## 5. 开发者工具调试

- [ ] 使用真实 AppID 打开 `miniprogram/` 目录。
- [ ] 检查首页首次进入、当前位置查询、手动地点搜索。
- [ ] 检查结果页评分、质量、最佳窗口、云层、能见度、湿度、气溶胶摘要。
- [ ] 检查分享地图入口和照片上传入口。
- [ ] 检查 storage 中 session token、最近查询、收藏缓存不会写入敏感明文。
- [ ] 检查接口失败、超时、空结果时的错误提示。
- [ ] 开发阶段可以临时打开“不校验合法域名”，但提交体验版前必须关闭重测。

## 6. 真机验收矩阵

iOS 至少一台，Android 至少一台。每台都记录机型、系统版本、微信版本、基础库版本、测试账号和测试时间。

- [ ] iOS：首次进入首页，无缓存状态正常。
- [ ] Android：首次进入首页，无缓存状态正常。
- [ ] iOS：允许定位后可用当前位置查分。
- [ ] Android：允许定位后可用当前位置查分。
- [ ] iOS：拒绝定位后可手动搜索地点。
- [ ] Android：拒绝定位后可手动搜索地点。
- [ ] iOS：城市搜索能返回地点并进入结果页。
- [ ] Android：城市搜索能返回地点并进入结果页。
- [ ] iOS：结果页评分和指标不溢出、不遮挡。
- [ ] Android：结果页评分和指标不溢出、不遮挡。
- [ ] iOS：分享卡片标题、路径、图片口径正确。
- [ ] Android：分享卡片标题、路径、图片口径正确。
- [ ] iOS：照片上传可选择相册图片并成功提交。
- [ ] Android：照片上传可选择相册图片并成功提交。
- [ ] iOS：拒绝相册/拍摄权限后可返回并重新授权。
- [ ] Android：拒绝相册/拍摄权限后可返回并重新授权。
- [ ] iOS：弱网下请求失败有明确提示且可重试。
- [ ] Android：弱网下请求失败有明确提示且可重试。

## 7. 体验版验收

- [ ] 使用 `miniprogram-ci` 或微信开发者工具上传体验版。
- [ ] 记录体验版版本号、上传时间、上传人、对应 Git commit 和 CI run。
- [ ] 保存体验版二维码或截图。
- [ ] 邀请体验成员扫码验证，不只依赖开发者工具模拟器。
- [ ] 体验版使用正式线上接口 `https://sunset.bjhyc.online`。
- [ ] 体验版验证通过后，再进入提审流程。

## 10. 阻断项

出现以下任一情况，不提审、不发布：

- [ ] 合法域名未配置或必须依赖“不校验合法域名”才能运行。
- [ ] 定位拒绝后无法手动搜索。
- [ ] 照片上传失败后没有明确提示或重试路径。
- [ ] 分享卡片路径错误，无法回到结果页或对应入口。
- [ ] 隐私协议未覆盖位置、照片、拍摄时间、用户标识。
- [ ] iOS 或 Android 任一平台核心流程未验收。
- [ ] GitHub CI 未通过。
