API 接入

本页说明霞客 Agent API 的接入方式，含鉴权、参数、返回值与示例。

仅限个人/学习/研究用途，禁止商用。任何公开展示请脱敏并标明来源。

申请 API 账号 下载 OpenAPI 规格 前往管理后台

快速开始

  1. 申请并获取 Token（管理员审核后返回明文 token）。
  2. 请求时在 Authorization: Bearer <token> 中传入。
  3. 支持请求：/api/agent/forecast、/api/agent/explain、/api/agent/geocode。

Token 使用

鉴权头示例：

Authorization: Bearer YOUR_TOKEN_HERE

注意：不要在代码里硬编码真实 Token，可在环境变量/配置文件注入。

示例调用

curl

curl -H "Authorization: Bearer YOUR_TOKEN_HERE" \ "https://your-host/api/agent/explain?location=%E5%8C%97%E4%BA%AC&type=sunset&date=today"

JavaScript

const res = await fetch('/api/agent/geocode?q=%E5%8C%97%E4%BA%AC', { headers: { 'Authorization': `Bearer ${token}` } }); const body = await res.json(); console.log(body.data.top.name, body.data.top.countryCode);

Python

import requests url = 'https://your-host/api/agent/forecast' resp = requests.get( url, params={'location': '北京', 'type': 'sunset', 'date': 'today'}, headers={'Authorization': 'Bearer YOUR_TOKEN_HERE'} ) print(resp.json())

参数表（核心）

接口参数说明
/forecast lat lon location type date detail 日落/朝霞预测，返回评分与窗口。
/explain lat/lon 或 location，type，date 输出评分构成、因子关系、关键限制与自然语言解释。
/geocode q(必填)、limit(选填) 返回标准地点列表，包含坐标和置信度。

返回字段（示例）

  • /forecast：location, score, quality, bestViewingWindow, meta.algorithm, etc.
  • /explain：factorRelations, scoreComposition, constraints, explanation.narrative。
  • /geocode：results[].name, country, countryCode, lat, lon, confidence, rankReason, provider。

错误码

状态码错误码含义
400INVALID_PARAMS参数缺失或不合法
401UNAUTHORIZED缺少/无效 token
403SCOPE_DENIED / TOKEN_DISABLED权限不足或 token 禁用
404LOCATION_NOT_FOUND未找到地名
429RATE_LIMITED / RATE_LIMIT_EXCEEDED请求过于频繁
500AGENT_*_ERROR内部异常

限流与安全

  • Token 具备分钟/日两级限流，超限返回 429。
  • 受邀用户 Token 会记录用途备注、非商用标记和可选到期时间，后台可随时单个停用或批量禁用。
  • 默认额度仅面向个人、学习、研究、测试等非商业场景；不得转卖、转租或用于商业产品。
  • /api/agent/openapi.json 同样受全局限流保护。
  • 鉴权头只支持 Authorization: Bearer <token> 与兼容头 X-Xiake-Token。
