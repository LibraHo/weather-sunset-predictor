当前方案的刷新计划

切到 old 时这些时间点触发 Open-Meteo 刷新；切到 new 时触发 GFS+CAMS run。请先确认当前方案再保存。

方案参数

old 参数和 new 参数分开放置。old 只看 Open-Meteo 缓存；new 才配置 bbox、分辨率、GFS/CAMS 和预算估算。

old 参数

Open-Meteo 旧链路当前只有晚霞/朝霞缓存状态和手动刷新，不使用 new 的范围、分辨率或 GFS/CAMS 开关。

new 参数

业务区域定义 old 和 new 共用；old 固定 1°，new 额外使用下载 bbox、分辨率和预算估算。

不规则区域
用于过滤真实业务区域；bbox 只是 new 下载外包矩形。
地理边界高级设置

只有选择自定义地理边界时才需要手动改；普通场景用业务覆盖范围即可。

数据源
GFS/CAMS 是 new 的主源；old fallback 只用于降级。
